# NavBot Isaac Sim experiment scripts

These scripts accompany [the runtime validation record](../../../docs/isaac-sim-runtime-validation.md). They require Isaac Sim 6.1 and the existing NavBot project scenes, not included in this small script download. They are not universal robot importers.

Run one script at a time in Isaac Sim's Script Editor. Save user edits first, stop playback, open the required scene and use the synchronous-rendering launcher. All scripts schedule an async main(); do not wrap them again or run with ordinary system Python.

- control_navbot.py: open isaacsim/scenes/navbot_drive_test.usda. Tests forward and left turn, zeros drive targets and stops. Writes tests/physics/robot_import/drive_test_report.json.
- test_corridor_collision.py: open isaacsim/scenes/navbot_corridor_test.usda. Requires spawn (-0.28,-3.0,0.03), +Y heading, Floor/Walls geometry and exact prim paths from the article. Floor query plus pose sampling establishes local blocking, not contact-force measurement or complete collision validation. Writes tests/physics/robot_corridor/motion_report.json.
- record_corridor.py: open the same corridor scene. Creates two timestamped MP4 clips in tests/physics/videos. Motion schedule is part of the script. Titles and concatenation are subsequent editing, not generated by this script.

Public versions remove machine-specific paths and add Script Editor async entry points. Flat-drive timing uses actual timeline time, like the corrected corridor test. They leave scene edits in memory without automatically saving the USD. Measurements overwrite their named report, videos use timestamped names. Model-dependent coordinates, prim paths and thresholds must be adapted for other robots/scenes.

Before publishing, all three public scripts completed in Isaac Sim 6.1. The control and collision assertions passed, and the capture script produced both MP4 files. This validates the current project setup, not other environments.
